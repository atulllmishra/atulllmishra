### 🎮 Game 3: 🐛 "Spot the Bug" Debugger Challenge

Inspect the JavaScript snippet below. Can you identify the subtle bug?

```javascript
function calculateCartTotal(cartItems) {
    let total = 0;
    for (var i = 0; i < cartItems.length; i++) {
        setTimeout(function() {
            total += cartItems[i].price;
        }, 100);
    }
    return total;
}
```

<details>
<summary><b>🔍 Click here to check if you spotted the bug!</b></summary>
<br />
<blockquote>
  <b>🐛 Bug Found:</b><br />
  1. <code>calculateCartTotal</code> returns <code>total</code> synchronously (which is <code>0</code>) long before the asynchronous <code>setTimeout</code> callbacks execute!<br />
  2. In the loop, <code>cartItems[i]</code> will evaluate to <code>undefined</code> inside the callback because <code>var i</code> is function-scoped and reaches <code>cartItems.length</code> by the time the timer fires!<br /><br />
  <b>✅ Fix:</b> Use <code>async/await</code>, <code>Array.prototype.reduce()</code>, or block-scoped <code>let</code>!
</blockquote>
</details>
